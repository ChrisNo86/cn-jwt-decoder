# CN JWT Decoder

Professional JSON Web Token (JWT) Decoder built with HTML, CSS and JavaScript.

A fast, lightweight and privacy-friendly tool for decoding and inspecting JWT tokens directly in the browser. No data is transmitted to external servers.

## Features

### Token Decoding

* Decode JWT headers
* Decode JWT payloads
* Automatic JSON formatting
* Human-readable output

### Token Inspection

* Expiration date detection
* Expiration status validation
* Invalid token detection
* Error handling

### Productivity

* Copy decoded content
* Instant decoding while typing
* Responsive interface
* Mobile-friendly design

### Privacy

* 100% client-side processing
* No server required
* No tracking
* No data storage

## Installation

Clone the repository:

```bash
git clone https://github.com/ChrisNo86/cn-jwt-decoder.git
```

Open:

```text
index.html
```

No build process required.

---

## Usage

1. Paste a JWT token into the input field.
2. The decoder automatically parses the token.
3. View header information.
4. View payload information.
5. Inspect expiration details.
6. Copy decoded data if needed.
